# Семантичні терми

Реалізація: [`src/sipl/semantics/terms.py`](../src/sipl/semantics/terms.py)
(побудова) та [`evaluate.py`](../src/sipl/semantics/evaluate.py) (обчислення).

## Побудова терму (SEM-01)

Терм будується рекурсивно за структурою AST. `sem_P`, `sem_S`, `sem_A`,
`sem_B` - семантичні відображення для програм, операторів, арифметичних
виразів та умов.

| Синтаксис | Терм |
|---|---|
| `begin S end` (програма) | `sem_S(S)` |
| `x := e` | `AS^x(sem_A(e))` |
| `S1 ; S2` | `sem_S(S1) • sem_S(S2)` |
| `if b then S1 else S2` | `IF(sem_B(b), sem_S(S1), sem_S(S2))` |
| `while b do S` | `WH(sem_B(b), sem_S(S))` |
| `begin S end` (оператор) | `sem_S(S)` |
| `skip` | `id` |
| `n` | `n̄` |
| `x` | `x⇒` |
| `e1 + e2`, `e1 - e2`, `e1 * e2` | `S^2(add \| sub \| mult, sem_A(e1), sem_A(e2))` |
| `e1 = e2`, `e1 > e2` | `S^2(eq \| gr, sem_A(e1), sem_A(e2))` |
| `b1 ∨ b2` | `S^2(or, sem_B(b1), sem_B(b2))` |
| `¬ b` | `S^1(neg, sem_B(b))` |

Композиція `•` асоціативна, тому `(f • g) • h` записується як `f • g • h`.

`sipl term --explain` друкує послідовність застосованих правил; кожен
підтерм пам'ятає `SourceSpan` фрагмента, з якого його отримано.

Нотації: `unicode` (`AS^R(1̄) • WH(...)`, `X⇒`), `ascii` (`const(1)`, `X=>`,
`*` замість `•`) та `latex`.

## Обчислення на стані (SEM-02)

Стан `st` - часткове відображення імен змінних у цілі числа.

| Правило | Перехід |
|---|---|
| `const` | `n̄(st) = n` |
| `deref` | `x⇒(st) = st(x)`; не визначено, якщо `x` немає у стані |
| `S` | `S^n(f, g1..gn)(st) = f(g1(st), ..., gn(st))` |
| `AS` | `AS^x(t)(st) = st ∇ [x ↦ t(st)]` |
| `•` | `(f • g)(st) = g(f(st))` |
| `IF-true` / `IF-false` | `IF(b, f, g)(st) = f(st)` або `g(st)` залежно від `b(st)` |
| `WH-true` | якщо `b(st)` істинне: `WH(b, f)(st) = WH(b, f)(f(st))` |
| `WH-false` | якщо `b(st)` хибне: `WH(b, f)(st) = st` |
| `id` | `id(st) = st` |

Результат - кінцевий стан або **невизначеність** із причиною:

* `undefined_variable` - терм звернувся до змінної без значення;
* `step_limit` - перевищено ліміт переходів (`--max-steps`, типово 10 000).

## Межі автоматизації

Чи завершується цикл - алгоритмічно нерозв'язне питання. Обчислювач **не**
доводить зациклення: він лише повідомляє, що в межах ліміту кроків значення
не отримано. Цілі числа необмежені (переповнення немає).
